# Повторный простой сборщиков — 26.10.2026

Unity 6000.6.6f1. [Правила исправления](../specs/026-helper-idle-recovery.md).

Предыдущий контроль застревания выполнялся только внутри WalkTo. Выходы
из Update при ожидании замаха, отсутствии цели и доставке его обходили.
Рабочий маршрут также пересчитывался каждые полсекунды, что могло возвращать
сборщика к другим начальным узлам вместо продолжения пути.

Теперь независимая проверка раз в игровую секунду заново выдаёт задание
простаивающему сборщику: освобождает резерв, очищает путь/зависший callback
и задержки поиска. Проверка повторяется постоянно. Если предыдущая работа
была заблокирована, сборщик пробует отойти обычным движением в свободную
сторону на 0,65 м. Путь сохраняется, пока он пригоден; изменения цели,
препятствия и отсутствие пути вызывают новый поиск. Груз не выбрасывается,
а ожидание полного сырого склада у цеха и действующий замах не сбрасываются.

Исчезнувшие предметы исключаются из переносимого груза. Раньше null в списке
мог сохранять Count > 0, а доставка пропускала его без удаления — получалось
постоянное возвращение с фактически пустым грузом.

Отдельно воспроизведена вечная доставка положительного остатка 0,00001 кг:
проверка до исправления падала, потому что разгрузка пропускала массу меньше
0,0001 кг, хотя предмет продолжал числиться грузом. Теперь любой положительный
остаток передаётся в цех через существующую приёмку массы.

## Проверки

В настоящем Unity Editor Play Mode прошли 17 новых проверок:
[лог восстановления](026-helper-recovery.txt). Включены повторные сбросы
простоя, новая добыча после исчезновения груза, намеренно зависший callback,
обход стены с сохранением пути, выход из перекрытия коллайдером персонажа,
ожидание полного склада, последующая доставка, маленький остаток и пауза.
Тест маленького остатка сначала воспроизвёл ошибку старого порога разгрузки,
после изменения порога прошёл.

Также прошли 83 проверки предыдущего обновления ([лог](026-workers.txt)),
175 экономики и 99 переноски ([лог](026-regressions.txt)). Всего 374
успешных утверждения Editor Play Mode. .NET-компиляция использовалась
отдельно как вспомогательная диагностика исходников.

Windows development build создана Unity 6000.6.6f1: 0 ошибок,
495 предупреждений пакетов/шейдеров и существующей настройки Pipeline.
[Сборка](026-windows-build.txt), [предупреждения](026-windows-build-warnings.txt).
Готовая игра отдельно запущена через `tools/TestWindowsBuild.ps1`:
105 проверок прошли, настройки экрана восстановлены.
[Лог Windows](026-windows-smoke.txt). В него дополнительно входят настоящее
повторное переназначение задания, новая добыча после исчезновения груза,
подбор и передача маленького остатка в цех с начислением опыта приёмки.

[Аудит](026-assets.txt): 389 объектов, 0 missing scripts и неразрешённых
GUID; все исходные `.meta` сохранены, новый скрипт проверки имеет `.meta`.
Исторические отчёты/снимки 025 сохранены. Автоматические изменения GI монет
и preloadedAssets после сборки убраны из состава изменения. Пользовательские
настройки URP/подключения Unity и ArtBook в коммит не входят.

Полностью перекрытая дорога не становится проходимой от сброса задания:
сборщик продолжает попытки и сохраняет груз. Конечный набор воспроизведений
не доказывает отсутствие всех возможных блокировок в длительном матче.
