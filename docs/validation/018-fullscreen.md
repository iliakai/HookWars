# Восстановление полноэкранного запуска — 25.10.2026

Причина: проверка сборки017 запускала exe с `-screen-fullscreen 0`,
`-screen-width 1280 -screen-height 720`. Unity сохранил оконный режим
в HKCU/Software/DefaultCompany/HookWars. Настройки проекта не менялись:
fullscreenMode=1 (FullScreenWindow), полноэкранное нативное разрешение.

Перед исправлением у текущего пользователя режим был 3 (Windowed),
разрешение 1280×720, Use Native=0. Восстановлены режим1 и Use Native=1.
Остальные пользовательские параметры не сбрасывались.

Добавлен `tools/TestWindowsBuild.ps1`: сохраняет имена, значения и типы
параметров Screenmanager/UnitySelectMonitor до запуска оконного автотеста
и восстанавливает их в finally после завершения процесса, включая сбой.
При уже запущенном HookWars тест отказывается стартовать. Unity service
параметры и игровые предпочтения скрипт не изменяет.

Запуск из корня проекта от обычной пользовательской учётной записи:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File tools/TestWindowsBuild.ps1
```

Проверено на готовой сборке017, без изменения игрового кода/пересборки:

- Новый скрипт выполнил **65** успешных проверок Windows exe, код выхода0;
  после теста настройки экрана восстановлены.
- Обычный exe запущен без параметров экрана. Win32 GetWindowRect:
  **0,0,3440,1440**, границы монитора GetMonitorInfo: **0,0,3440,1440**.
  Окно покрывает весь монитор. Проверочный процесс штатно закрыт через WM_CLOSE.
- После обычного запуска сохранены режим1 и Use Native=1.

Это проверка фактического размера окна; визуальная оценка игры не проводилась.
