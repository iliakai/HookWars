## Что покрыто

- Ровно одна смерть героя/животного создаёт одну собственную тушу; при смертельном хуке доставляется весь прежний груз. Старые 97 проверок массы, захвата, переполнения, отмены, возрождения, счёта, отскоков, длины цепи и размеров/направления крюка сохранены.
- Цех: уникальность без списания, приёмка целых туш 12 кг из 18 кг, полный цех и оставшиеся 6 кг, автоматическая приёмка после освобождения места, ровно один XP за принятые кг, переработка в продукцию/кости, остатки костей, независимые владельцы, три апгрейда, ускорение частично обработанного сырья, новый XP только на будущую сдачу, ресурсы после смерти.
- Лавки: один склад на две лавки, отсутствие повторной продажи, пустой склад без дохода/XP, одинаковый результат 100 малых шагов и одного большого, изолированные цены/владельцы, прирост цены без скорости, отключённый legacy-доход.
- Фермы: независимые таймеры, свободная суша обоих берегов, 48 появлений на глубинах 4/20 м, ограниченный отказ на полностью занятой карте, локальное улучшение и положительный минимум. Животные без Health, повторный Kill возвращает ту же тушу, топор убивает корову за один удар, прямой/обратный хук переключается на тушу и подбирает её. Проверены препятствие/река и остановка Animator.
- GIF: 12 полных PNG попиксельно/по альфа и времени сверены с независимым Windows-декодером. В Unity проверены ключи, 0,64 с, loop, canvas, pivot и PPU. Unity добавляла 10 мс после последнего Sprite-ключа; исправлена конечная выдержка. См. ../animal-animation-import.md.
- Стены: свой/чужой крюк, сначала урон, выживание с отскоком и без, разрушение с нулевым/положительным запасом и продолжение полёта без расхода, отсутствие повторного численного урона, апгрейд сохраняет повреждения, расход только костей. Коллайдер выключается сразу, ходьба/клетка освобождается. Возможен выход из начального пересечения после посадки хуком.
- Строительство: крайняя клетка у гор при 4/20 м, запрет перекрытия/реки/чужого берега/границ и промежуточных координат, отсутствие оплаты при отказе, размер корня/коллайдера 1×1 и пропорциональная графика всех четырёх зданий.

## Повторение

В открытом Editor вне Play Mode: **HookWars → Economy → Check all stages**. Перед запуском сохраните нужные изменения сцены. Инструмент выполняет явную настройку, затем ждёт окончания импорта/перекомпиляции и проверяет несохраняемую тестовую сцену.

Для batch mode закрыть Editor с этим проектом, подготовить папку Temp/CarryingValidation и выполнить:

```powershell
& 'C:/Program Files/Unity/Hub/Editor/6000.6.6f1/Editor/Unity.exe' `
  -batchmode -nographics -projectPath 'C:/Users/iliak.ILIAPC/HookWars' `
  -executeMethod EconomyChecks.Run5 `
  -logFile 'C:/Users/iliak.ILIAPC/HookWars/Temp/CarryingValidation/economy5.log'
```

Не добавлять `-quit`: инструмент выходит после возврата в Edit Mode с кодом успеха/ошибки. GUI-процесс Unity в Windows может вернуть управление оболочке до завершения; нужно дождаться итоговых строк или завершения процесса.

## Практические ограничения

Это сценарный инструмент на реальных компонентах и Physics2D с управляемыми вызовами шагов, а не полная симуляция ввода и не NUnit suite. Визуальный матч, поведение интерфейса в разных размерах окна, производительность большого числа животных и Windows player build не подтверждаются этими тестами. Отдельно вручную проверить полный цикл туша → цех → продукция/кости → лавки/стены, покупку трёх веток цеха, анимации животных и стены в бою с ИИ.
