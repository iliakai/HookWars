## Ассеты

Прочитаны README_RU, validation, исходный сборщик и скрипт отображения из
`Temp3DModel/Gold Coin`. Импортированы статический FBX и7PBR-текстур;
из Mountains —бесшовная PNG. Оригиналы не изменены, внешние сборщики/демосцены
не запускались, .blend/.glb/видео/чужие runtime-скрипты в Assets не перенесены.
9исходных файлов совпадают с Temp3DModel побайтно:
[SHA256](022-imports.txt).

В Unity выявлена неверная ориентация поверхностей монеты. Для отрисовки
создан отдельный GoldCoinRender.asset с исправленными индексами, нормалями
и знаком касательных. FBX сохранён исходным. Материалы двусторонние,
с исходными картами и цветным заполнением, без добавления источников света.
Локальный keyword emission включён явно, флаг материала BakedEmissive нужен
для сохранения режима; динамического GI/запекания в этом этапе нет.
Применяемый API: [Unity Material.EnableKeyword](https://docs.unity3d.com/kr/current/ScriptReference/Material.EnableKeyword.html).

Каменная текстура повторяется по метрам на обеих границах, без растяжения
на всю20мстену. Логические коллайдеры/размеры поля сохранены.
