# Текущее состояние HookWars

Unity6000.6.6f1, ветка feature/arena-25d. Актуальные доработки:
[009 — развитие, карта и помощники](specs/009-gameplay-development.md).
Архитектура/модели/цепь —008, анимации мясника —007, экономика —001–005
с поправками009. Исторические проверки008 не заменяют новые проверки009.

## Запуск и управление

Открыть Assets/Scenes/MainMenu.unity и нажать Play. По умолчанию Editor
начинает с MainMenu; меню HookWars/25D/Launch позволяет Play текущей сцены.
Прямой Arena25D использует16м. Windows profile StandaloneWindows64:
MainMenu, затем Arena25D, без старых сцен. Глубина4–20, река4, длина20м,
общая ширина2×глубина+4. Размер применяется до Awake героев и спавнов.
Первый выбор16, затем bank-depth.txt в Application.persistentDataPath.

- WASD — движение, ЛКМ — крюк вне строительства, ПКМ — топор.
- Tab/кнопка «Развитие» — отдельное окно карточек навыков с «+».
- B — выбор постройки; R — поворот90°; ЛКМ — строить подряд до Esc.
- E и цифровые1–8 больше не покупают/не размещают объекты.
- Клик по своему зданию — его улучшения; в цеху также заказ помощника.
- Esc сначала закрывает активные окна/стройку, затем открывает паузу.

Развитие блокирует игровые клики. Недоступная покупка не тратит очко.
Открытие окон не двигает камеру; ортографическая камера55° учитывает поле,
aspect и боковые панели, без ручного зума/поворота/перемещения.
Выход в меню удаляет матч/цепи/помощников/таймеры, восстанавливает timeScale.
Новый бой:0 золота,+2/с,XP0 без пассивного опыта, базовые навыки/счёт/
склады/помощники. Сохраняется только выбор глубины.

## Развитие и кг

Каждый уровень даёт одно очко. Меню2×5 показывает текущее значение и эффект
покупки. За одно очко:

| Навык | Прибавка |
|---|---|
| Дальность крюка | +1м |
| Урон крюка | +10кг |
| Ширина крюка | +.1м |
| Скорость крюка | +1м/с |
| Перезарядка крюка | −.25с, минимум1с |
| Урон топора | +5кг |
| Размах/размер топора | +.2м радиуса сектора и пропорциональный размер меша |
| Скорость героя | +.25м/с |
| Регенерация | +.1кг/с |
| Переноска | +2кг |

Крюк улучшается после завершения броска, топор — после текущего замаха.
Начальные Player:крюк12м/40урон/10мс/6с, топор20урон/1.6м/100°/.7с,
скорость5м/с. Enemy сохраняет исходный бой/ИИ. Отскоки врождённо без
счётчика и без платных навыков. Полная длина цепи ограничена Range,
дальность отдельного участка после контакта остаётся50% Range.

Здоровье — кг.100 в начале, каждый уровень умножает максимум на1.1:
100→110→121. Рост сохраняет долю текущего здоровья и не воскрешает.
Регенерация живого героя .1кг/с с учётом игрового времени; смерть и пауза
останавливают её. Возрождение восстанавливает текущий максимум.
Туша героя хранит максимум в момент смерти. Позднейший уровень не
изменяет уже отдельную тушу. Подбор остаётся только целыми тушами:
начальный груз10кг и сырьё12кг не принимают100кг без улучшений.

## Карта и строительство

Единственный ArenaLayout задаёт метры, берега, реку и границы. После него
MatchMap25D до обычных Awake/экономики бесплатно создаёт по одному пустому
цеху каждому владельцу в свободном случайном месте тыловой трети его берега.
Основание2×2м, четыре клетки; ручного строительства цеха нет. Модель и
proxy масштабируются по основанию, собственный коллайдер ровно2×2.

На обоих берегах1–6 постоянных груд RockPile в зависимости от размера поля.
Источник:3dModelsImport/Stones,22камня/4336треугольников, FBX+палитра URP.
Без .blend/демосцен в Assets. Основание1×1м, модель.96м. Нет Health или
функции удаления; блокируют ходьбу/стройку/спавн и отражают крюк. Исходные
герои и подходы к цехам не перекрываются. Генерация ограничена попытками
и повторно не создаёт объекты в том же матче; новый бой получает новую карту.

GameBuilding.Footprint задаёт проверяемую площадь. Все ручные постройки1×1,
цех2×2. Логический уголZ−90° отображается в3D yaw+90°. Предпросмотр использует
тот же масштаб/поворот без активных скриптов/FX. Выбор и угол сохраняются
после размещения; занятость/нехватка денег не снимают выбор и не списывают
ресурсы. Строительные клики не бросают крюк. Касание клеток/гор разрешено.

## Экономика, фермы и помощники

Лавка75 золота, ферма150, стена5 костей. Цех выдаётся бесплатно один раз;
12кг сырья,2с/кг,1кг продукции+.5кости+2XP/кг принятого сырья.
Лавка продаёт .5кг/с за5золота/кг. Всё принадлежит конкретному владельцу;
смерть не сбрасывает его экономику, новая сессия сбрасывает.

В цеху пять действий:три прежних улучшения, заказ помощника100 золота и
переноска помощников+2кг за50 золота с ростом ceil×1.5. База10кг, эффект
на текущих/будущих работников этого цеха. Временные параметры в Inspector.
Рабочие — половинные анимированные мясники, скорость3м/с, радиус.25м,
здоровье100кг, удар животного с.9м через.4с, кулдаун1с.

Охотятся только по берегу цеха независимо от позиции владельца. BFS.5м
учитывает постройки/камни/других существ; движение проверяет WorldCollision.
Удар через существующий HeroActionTiming повторно проверяет цель и вызывает
Animal.Kill один раз. Целая туша передаётся через CarcassCarrier в тот же
SausageFactory; опыт/продукцию/кости не начисляет новая параллельная система.
Полный цех оставляет груз рабочему, доставка повторяется после освобождения.
При захвате движение и действие отменяются; смерть выбрасывает груз/
отдельную тушу, объект удаляется после завершения притягивания.

Ферма выбирает берег по своему X, не по владельцу:24 попытки свободного
места, повтор через1с без очереди. Животные гуляют по берегу рождения.
Cow/Pig/Sheep имеют Walk/Graze по реальной добровольной скорости, при упоре
шаг останавливается, через.22с Graze; захват замораживает анимацию. Массы
4/10/6кг(овца/корова/свинья). После смерти — вращающееся мясо по spec010, без боевых скриптов/событий.

## 3D-архитектура и цепь

ArenaSpace25D:(x,y)→(x,высота,y),1единица=1м,+Z вперёд. Игровая XY/Physics2D
отделена от графических корней XZ. В игровом мире нет SpriteRenderer/GIF/
LineRenderer или запасных капсул/кубов сущностей. Груз — вращающиеся модели мяса,
здоровье — billboard вне BodyRoll.

Мясник Generic/Root Motion off;8Roll из фактического движения относительно
взгляда, фаза/ориентация сохраняются при остановке/повороте. BodyRoll,
AxePivot и ChainArm разделены масками. Производный CenteredBody исправляет
исходный эллипсоид без изменения FBX:scale.48,radius.4992м,центр.5142м,
низ.015м; покадрового BakeMesh/AABB-подъёма нет. AxeVisualScale влияет только
на проверенные05/06 части топора, без масштабирования головы/тела/коллайдеров.
Для помощников эффективный радиус учитывает половинный масштаб.

HookAbility единолично считает попадания, урон, отскоки и маршрут. Физическая
HookWarsChain выдаёт/втягивает динамические кольца из пула между кинематическими
креплениями руки/крюка/изгибов. Шаг.168×scale, округление не расширяет Range.
Изолированная LocalPhysicsScene3D, слои24/25, один envelopeCollider/звено,
прокси земли/гор/зданий/камней, без контактов с владельцем/грузом/соседями.
LateUpdate после окончательных поз, подшаг≤fixedDelta/16, локальные solver128,
projection off. Смерть/отмена/выход освобождают активные звенья и весь пул с матчем.

## 010 — графика мяса

После убийства вместо тел появляется модель MeatOnBone из предоставленного
Meat. Все животные — вариант.5м, герои —.9м; нижний край.25м над землёй.
Мясо плавно вращается вокруг вертикали (авторский Meat_Spin,4с/оборот)
без подпрыгивания. Груз также использует новую модель. Логические массы,
Collider2D, подбор, притягивание и сдача сохранены. На графике только безопасный
Animator без боевых событий/скриптов. Прежние упоминания «статичной туши
без Animator» заменены этим визуальным циклом.40 новых Play Mode и27
регрессий животных прошли; кадры просмотрены. См. spec010.

## 012 — готовое мясо, склад и скорость продаж

1 кг сырья даёт 0,5 кг готового мяса и 0,5 кг костей. Склад готового мяса
12 кг (подтверждено пользователем); его запас/вместимость показаны в HUD.
Полный склад блокирует приёмку и переработку без потери сырья; фактическая
продажа освобождает место. Вместимость цеха увеличивает оба склада на12кг.
Лавка уровня1:0,05кг/с ×10золота/кг =0,5золота/с; за уровень ещё0,5/с,
растёт скорость, цена10/кг сохраняется. Кости отображаются в кг.
Сумма золота без дробей, точные остатки сохранены внутри. Доход обновляется
по реальным начислениям, с половиной золота при необходимости:2/2,5/3…
