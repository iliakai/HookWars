# Импорт анимаций животных

Исходники сохранены без изменения: `Assets/Textures/Animals/sheep_walk.gif`, `cow_walk.gif`, `pig_walk.gif`. Unity импортировала по **одному Sprite** на GIF: готовой последовательности AnimationClip не было.

Каждый GIF содержит 4 кадра на холсте 384×384, задержки 160/160/160/160 мс. Все используют прозрачный индекс и disposal=2. После первого полного кадра идут частичные прямоугольники со смещениями; простое сохранение локальных прямоугольников дало бы скачки и неверное наложение.

`tools/extract_gif.py` (Python 3, только стандартная библиотека) декодирует LZW/палитры, прозрачность, смещения, interlace и disposal 0–3 по [первичной спецификации GIF89a](https://www.w3.org/Graphics/GIF/spec-gif89a.txt), сохраняет полные скомпонованные RGBA PNG. GIF — формат и service mark CompuServe. Для данных исходников фон после disposal=2 очищается до прозрачного перед следующим кадром. Исходники не перезаписываются. Манифесты `Assets/Textures/Animals/Frames/*/frames.json` содержат порядок, задержки, исходные прямоугольники/disposal и SHA-256 источника/пикселей.

Реально выполнены `python tools/extract_gif.py` и независимая проверка `powershell -NoProfile -ExecutionPolicy RemoteSigned -File tools/ValidateGifFrames.ps1`. Проверка использует встроенный декодер GIF Windows (System.Drawing), сравнивает все 12 кадров попиксельно по альфа и видимому RGB и проверяет задержки. Все совпали. Новые зависимости Unity или Python не нужны. Пробная установка Pillow не состоялась из-за цепочки SSL-сертификатов; работа от Pillow не зависит.

EconomySetup.Stage4 импортирует PNG в Sprite Single, без сжатия/мип-карт, PPU=480, pivot=(192,0) пикселей на общем canvas, то есть размер 0,8×0,8 м для любого кадра. Дочерняя графика смещена на −0,4 м по Y относительно центра круглого коллайдера радиусом 0,35 м. Обрезки кадров по разным размерам нет.

Созданы sheep/cow/pig_walk.anim и AnimatorController, цикл ровно **0,64 с**. Unity добавляет один sample после последнего ключа Sprite; поэтому финальный ключ в 0,63 с повторяет четвёртый кадр, а stopTime=0,64. Кадры переключаются в 0 / 0,16 / 0,32 / 0,48 с, длительность каждого 160 мс. При ходьбе Animator.speed=скорость/эталонная скорость; при блокировке 0. При смерти Animator отключён, отдельная туша использует текущий кадр.

В Unity проверяются длина/loop, кадры, pivot/canvas/PPU всех видов. Временные тестовые значения скоростей не сохраняются в игровых префабах. Визуальную плавность и размер животных в живом матче следует оценить вручную.
