# 014 — текстура реки и течение сверху вниз

Вода использует предоставленную бесшовную PNG из
`C:/Users/iliak.ILIAPC/3dModelsImport/River`, импортированную без изменения
исходных байтов как `Assets/Settings/River.png`. Отдельный материал
Arena25D-River: URP Lit, белый BaseColor, metallic0, smoothness0,65,
непрозрачная плоская поверхность. Repeat/mipmaps/Trilinear/aniso8,
max2048, sRGB, без CPU-копии текстуры.

Один повтор 4×4м. Скорость течения 0,6м/с, настраивается на
Arena25D Presentation в поле River Flow Meters Per Second.
Вершин волн/динамической жидкости/воздействия течения на игровые тела нет.

Поверхность реки — отдельный сохранённый Mesh с четырьмя вершинами,
U вдоль +X и V вдоль +Z. Это исключает зависимость направления от
стандартной UV-развёртки Unity Cube. Локальная высота0,5 при прежнем
размере/положении даёт ровно мировой Y=0, без наложения с берегами.
Материал и меш назначаются только реке. Physics2D и прокси цепи сохранены.

ArenaPresentation25D задаёт tiling/offset через MaterialPropertyBlock,
не меняет общий ассет материала и не создаёт материал каждый кадр.
Положительное смещение V движет изображение в -Z (логическое -Y),
то есть сверху вниз при текущей камере. Фаза берётся из игрового времени,
в паузе замерзает; при повторе бесшовной текстуры нет накопления offset.
Размеры реки по-прежнему берутся только из ArenaLayout (4×20м).

Настройка: `HookWars/25D/Setup flowing river`. Постоянные пути материалов,
меша и текстуры сохраняют GUID. После первичного импорта/автоматической
URP-миграции повтор настройки сохранил байты сцены, материала, меша и meta.

Проверка: `HookWars/25D/Preview river flow Play Mode` работает в уже
открытом Editor, делает два настоящих кадра Game View с промежутком около
секунды и проверяет назначение текстуры, изменение фазы, UV-направление,
проекцию движения вниз и остановку в паузе. Кадры014-river-a/b.png
просмотрены. Дополнительно направление проверено сопоставлением пикселей
воды двух кадров; результат в `docs/validation/014-river.txt`.
