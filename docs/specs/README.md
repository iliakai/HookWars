# Спецификации HookWars

Здесь хранятся принятые спецификации игровых систем. Полный согласованный дизайн — в `../game-design.md`; фактическое состояние — в `../current-state.md`.

- [001 — туши и переноска](001-carcass-carrying.md): первый этап. Новая переработка и торговля отложены, прежние доходы пока сохраняются.
- [002 — цех и переработка](002-processing.md): реализован; доходы переведены на 0 стартового золота, +2/с, без пассивного XP.
- [003 — лавки](003-shops.md): реализован; общий склад владельца и фактические продажи.
- [004 — фермы и животные](004-farms-animals.md): реализован; анимации из GIF, без числовой Health животных.
- [005 — стены](005-bone-walls.md): реализован; только кости, урон/отскоки/разрушение.

Пункт 001 описывает исторический переходный этап; актуальная экономика уже реализована этапами 002–005. Переноска вручную подтверждена пользователем и сохранена. Итоговые проверки — `../validation/002-005-economy.md`.

Для каждой спецификации фиксировать цель, правила и параметры, затрагиваемые системы, критерии приёмки и открытые вопросы. После реализации обновлять описание текущего состояния.

- [006 — прототип Arena25D](006-arena-25d.md): отдельная сцена, XY/Physics2D → XZ-отображение; фактический статус проверки указан в спецификации и отчёте.
