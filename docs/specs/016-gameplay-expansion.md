## Диагностика цепи у камня

Воспроизведён исходный разлёт в настоящем PhysX: два20м крюка, три броска
каждым, обычные камни0,629м и усиленный контакт с рукой (прокси1,5м).
До исправления:245активных тел/коллайдеров, скорость52971,910м/с,
ошибка joints127,692м, удаление от ближайшего владельца166,042м;
physics mean1,644мс, peak29,666мс. Точный отчёт016-chain-before.txt.
Причина — несовместимость жёсткого крепления с выталкиванием закреплённого
звена из пересекающего это крепление статического прокси.

Исправление: исключаются только пары collider закреплённых звеньев и
прокси, касающегося крепления (зона1м), пол не исключается. После выхода
из пересечения контакт восстанавливается, при остановке все пары сбрасываются.
У joints собственная PhysX-податливость1,5мм/spring2500/damper18 вместо
бесконечно жёсткого мгновенного исправления при выдаче звена. Локальный
Rigidbody.maxLinearVelocity35 дополняет прежние ограничения угловой скорости/
депенетрации. Это численная защита графической цепи, не ограничение Range
и не запись координат динамических тел скриптом.

Повтор того же теста:245тел/коллайдеров, скорость41,574м/с (после solver
может превышать pre-step maxLinearVelocity), ошибка0,314м, удаление8,008м.
Physics mean1,168мс/peak28,525мс. Разлёт не воспроизвёлся; report016-chain-after.txt.
Цепь остаётся реально динамической, кинематические только крепления;
объекты/скорости существующих звеньев сохраняются, пул используется повторно.

Штатная регрессия32проверки прошла: две30м цепи (>160звеньев каждая),
динамические тела/одно envelope collider, провисание, отскок, уничтожение
стены при активном хуке, обратное прохождение направляющих, серия бросков
без роста числа Rigidbody/joints, смерть. Максимум ошибки0,1640618м.
Профиль сохранён в016-chain-regression.txt. Пики CPU остаются ограничением
длинных/множественных цепей; это prototype PhysX, не spline-анимация.
