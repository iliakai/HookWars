# 022 — каменные границы, речные монеты, доход и часы матча

Задание25.10.2026. `Temp3DModel/` — постоянная папка входящих пользовательских
моделей. Используемые исходники копируются в Assets; оригиналы сохраняются.

- Каменная бесшовная PNG из Mountains применяется к прежним границам карты
  с равномерным масштабом текстуры по граням. Логические стены/Physics2D и
  размеры поля не меняются.
- Монета из Gold Coin появляется через случайные25–35игровых секунд после
  начала матча, затем с новым независимым интервалом25–35с. X случайный в
  пределах воды с учётом радиуса; появляется у верхнего края реки и плывёт
  вниз с её скоростью0,6м/с. За нижним краем монета пропадает. Одновременные
  монеты допустимы, накопленной очереди появления при задержке нет.
- Стоимость каждой монеты —равномерное случайное целое число25–75 включительно,
  задаётся один раз при появлении. Монета ловится на прямом/обратном ходе
  обычным крюком. Синий режим тоже притягивает монету к герою, без полёта к ней.
- При захвате течение/уход за край приостанавливаются. Отмена возвращает
  монету в точку захвата, затем течение возобновляется. Повторный захват
  другим крюком до освобождения запрещён.
- Золото начисляется один раз при доставке монеты к живому герою, сразу
  монета удаляется. Это разовая награда, не прибавка к постоянному доходу;
  XP/мясо/груз не меняются. Автоматического подбора при проходе рядом нет.
- Оба героя могут ловить монеты. ИИ отдаёт доступной монете в дальности
  приоритет, учитывает движение вниз/задержку броска и проверяет препятствия;
  при отсутствии подходящей монеты действует против героя как раньше.
- Начальный пассивный доход обоих владельцев0,5золота/с вместо2.
  Лавки прежние: общий доход при снабжённой лавке уровня1 —2,5/с,
  при двух уровня1 или одной уровня2 —4,5/с. Новый матч по-прежнему0золота.
- При доставке монеты возле героя появляется золотистое «+N», поднимается
  вверх и растворяется за1игровую секунду. Надпись не прибавляет доход/награду.
- Сверху по центру —таймер HH:MM:SS с начала матча, без сброса при смерти.
  Пауза останавливает течение, появления, таймер и всплывающие надписи.
  Новый матч сбрасывает таймер/монеты/интервалы/надписи.
- Импортируется статический FBX и готовые PBR-текстуры монеты. Вращение90°/с,
  мягкое качание±0,035м/2с —только в отделённой XZ-графике; нет демосцены,
  дополнительных игровых/3D-коллайдеров, двойной анимации или источников света.

Интеграция модели: у исходного FBX в Unity выявлены обращённые внутрь
грани/нормали. В отдельном GoldCoinRender.asset исправлены winding, нормали
и handedness касательных; исходный FBX сохранён побайтно. Золотые PBR-материалы
используют цветное заполнение через EmissionMap=BaseColor,
EmissionColor=(1,2;1,2;1,2), двустороннюю отрисовку, без runtime GI/дополнительного света: полностью
металлическая модель иначе чернеет без студийных отражений.
Всплывающие награды учитывают туман и не показывают позицию скрытого врага.

Приёмка: интервалы/целые награды/течение/исчезновение/пауза, оба режима и
направления крюка, отмена/конкуренция/единственная выплата после доставки,
ИИ, новый доход, часы/надпись/сброс матча, текстура без растяжения, реальная
графика монеты и изображения. Затем регрессии и обновлённый Windows exe.

Результат:384успешных утверждения в Editor Play Mode и97в готовом Windows
exe;0ошибок сборки. [Приёмка](../validation/022-river-coins-clock.md).
