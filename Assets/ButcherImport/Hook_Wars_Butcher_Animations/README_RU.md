# Hook Wars — мясник с анимациями и цепью

## Что внутри

- `Hook_Wars_Butcher_Animated.blend` — модель с ригом и 10 встроенными текстурами. Blender 4.2+.
- `Assets/HookWarsButcher/Models/Butcher_Animated.fbx` — модель и 11 клипов для Unity.
- `HookProjectile.fbx` — отдельный крюк для физического броска.
- `Textures` — внешние копии текстур для Unity.
- `Runtime` — управление анимациями, физическая цепь и необязательное демоуправление.
- `Editor` — сборщик материалов, Animator Controller, масок, префаба и тестовой сцены.
- `Idle.png`, `Roll.png`, `Axe.png` — реальные рендеры поз из Blender.

## Открыть в Blender

Открой `.blend`. Выдели `ButcherRig`; в Dope Sheet переключись на Action Editor и выбери клип. Нажми пробел для просмотра. Для клипов движения диапазон — кадры 1–31 при 30 FPS. Вращается только `BodyRoll`, голова и оружие не кувыркаются вместе с шаром. Весь персонаж перемещается корнем `ButcherRig`.

| Клип | Действие | Длительность |
|---|---|---|
| Roll_N | Вперёд | 1 с, цикл |
| Roll_NE | Вперёд-вправо | 1 с, цикл |
| Roll_E | Вправо | 1 с, цикл |
| Roll_SE | Назад-вправо | 1 с, цикл |
| Roll_S | Назад | 1 с, цикл |
| Roll_SW | Назад-влево | 1 с, цикл |
| Roll_W | Влево | 1 с, цикл |
| Roll_NW | Вперёд-влево | 1 с, цикл |
| Idle | Исходная поза | 1 с |
| Axe_Attack | Замах, вынос вперёд, удар, возврат | 0,8 с |
| Hook_Cast | Замах и выпуск крюка | 0,6 с |

N — локальное направление перед лицом: в Blender −Y, в Unity +Z. Это не фиксированное направление экрана: оно зависит от камеры и поворота персонажа. В демосцене WASD привязан к камере.

Вылет крюка и динамическая цепь не записаны в клип Blender: `Hook_Cast` анимирует руку/держатель, а дальнейшее движение считает Unity. Длина и изгиб остаются изменяемыми во время игры.

## Запуск в Unity

Код рассчитан на Unity 2022.3 LTS и Unity 6; предусмотрены варианты `velocity`/`linearVelocity`, старый и новый Input System. Фактическая компиляция и Play Mode в этих редакторах здесь не выполнялись.

1. Распакуй архив. Скопируй папку `Assets/HookWarsButcher` в `Assets` проекта. `.blend` копировать в Assets не требуется.
2. Дождись импорта и компиляции скриптов.
3. Выбери меню **Hook Wars → Create Animated Butcher Demo**.
4. Сборщик создаст новую папку `Generated`, префаб, контроллер и отдельную сцену. Уже открытая сцена остаётся загруженной, существующие файлы не перезаписываются.
5. Для чистой проверки закрой другие открытые сцены, предварительно сохранив свою работу. Запусти Play в `ButcherDemo`.

**Управление:** WASD/стрелки — движение относительно камеры; мышь — направление взгляда; ЛКМ — удар; ПКМ — бросок; R — возврат крюка. На уровне есть столбы и куб с Rigidbody для проверки столкновений и подтягивания.

Материалы создаются для установленного шейдера URP Lit, HDRP Lit или Standard. Настройка освещения конкретного проекта может потребовать корректировки, особенно в HDRP.

## Вращение шара

В контроллере есть 2D Blend Tree всех восьми клипов. При этом `rollByTravelledDistance = true` по умолчанию: `LateUpdate` вращает шар по фактически пройденному расстоянию и сохраняет угол при смене направления. Это предотвращает скачок фазы между разнонаправленными циклами и подстраивает вращение под скорость игры.

Чтобы смотреть именно записанные клипы, выключи `rollByTravelledDistance` у `ButcherAnimationDriver`. Голова и оружие остаются независимыми в обоих режимах. `sphereRadius` задаёт отношение пути к углу вращения. Root Motion выключен; перемещение задаёт контроллер игры.

## Как работает цепь

`PhysicalHookChain` создаёт независимые мировые Rigidbody с ограничителями расстояния `ConfigurableJoint`. Угловые степени свободы свободны; силы тяжести, инерция, ограничения длины и столкновения рассчитываются PhysX. Визуальные металлические звенья следуют за физическими узлами и чередуются на 90°.

При броске сегменты постепенно выдаются у руки. Когда герой отходит вбок, перемещается только точка крепления, а ранее вылетевшие сегменты сохраняют импульс и изгибаются. Это не заранее нарисованная дуга. Возврат постепенно укорачивает сегмент у руки и убирает подошедшие узлы.

| Поле Inspector | Значение по умолчанию | Назначение |
|---|---:|---|
| maxLength | 8 м | Максимальная выданная длина |
| launchSpeed | 16 м/с | Начальная скорость и скорость выдачи |
| reelSpeed | 7 м/с | Скорость втягивания |
| segmentLength | 0,22 м | Расстояние между физическими узлами |
| nodeRadius | 0,04 м | Радиус столкновения узла |
| segmentMass | 0,08 кг | Масса одного узла |
| hookMass | 0,5 кг | Масса крюка |
| chainGravity | 1 | Множитель силы тяжести цепи |
| projectileGravity | 0,15 | Множитель силы тяжести летящего крюка |
| solverIterations | 24 | Число итераций решателя |
| latchHoldSeconds | 0,4 с | Пауза после зацепа перед возвратом |
| autoRetractAtRange | true | Возвращать после выдачи всей длины |
| visualLinkPitch | 0,1 м | Шаг нарисованных объёмных звеньев |

`maxLength` можно менять перед следующим броском. Значения длины и шага фиксируются на время активного броска, чтобы изменение Inspector не разорвало уже созданные соединения. Лимит — 128 физических сегментов; Inspector ограничивает максимальную длину в зависимости от шага.

Попадание в динамический Rigidbody прикрепляет к нему крюк: возврат может подтягивать объект. Зацеп за неподвижную поверхность освобождается перед втягиванием. Если игрок насильно разводит закреплённые концы дальше допустимого натяжения, зацеп освобождается. Рука управляется кинематически: цепь не тянет персонажа обратно. Для такого поведения нужен Rigidbody-контроллер персонажа и отдельная интеграция обратной силы.

Это дискретная игровая симуляция цепи, а не точная модель каждого металлического звена. Сталкиваются сферические физические узлы; визуальные кольца не имеют отдельных коллайдеров. Самостолкновения цепи выключены ради устойчивости. Узкая преграда между узлами может быть пропущена: уменьшай `segmentLength` и проверяй стоимость. При многих одновременно брошенных цепях потребуется профилирование, pooling/LOD. Физика не гарантирует одинаковый результат в сетевых клиентах.

Телепорт руки более чем на 4 м за один физический шаг сбрасывает цепь. Если застрявший возврат превышает `retractTimeout`, цепь убирается с событием `onRetractionTimeout`; это аварийное освобождение, а не физическое протягивание сквозь преграду.

Рекомендуемый стартовый Fixed Timestep — 0,02 с. Сборщик не меняет глобальные настройки проекта.

## Подключить к существующему контроллеру

Применяй созданный `Butcher.prefab` как основу визуального персонажа. `ButcherDemoInput` добавляется только в демосцену; на рабочем персонаже используй свой контроллер.

```csharp
// Ссылки на компоненты персонажа.
ButcherAnimationDriver anim;
PhysicalHookChain chain;

// Атака. Ударное событие через 0,4 с.
anim.Attack();

// Бросок в мировом направлении. Выпуск после замаха: 7/30 с.
anim.CastHook(targetWorldPosition - chain.socket.position);

// Принудительный возврат.
chain.Retract();

// Длина СЛЕДУЮЩЕГО броска.
chain.maxLength = 12f;
```

`onAxeImpact` — момент удара для звука/эффекта. `onAxeHit(Collider)` — попавшие в область лезвия цели; урон не назначается автоматически. `onHookHit(Collider)` — попадание крюка. `onReturned` — завершение обычного возврата. Эти события надо подключить к существующим системам здоровья, переноса груза и правил захвата. Старый HookAbility в этот пакет не включён и не изменён.

Не подключай одновременно этот физический крюк и старый скрипт, который принудительно двигает тот же снаряд через Transform: у полёта должен быть один владелец.

## Что проверено

- Blender: восемь циклов замкнуты по ориентации; голова изолирована от вращения шара.
- Реальные рендеры поз движения и удара.
- FBX экспортирован и повторно импортирован: 11 клипов, 7 костей, 6 частей модели.
- Текстуры встроены в `.blend`, для Unity находятся в `Textures`.
- Синтаксис всех C#-файлов проверен парсером C#; это не заменяет компиляцию с Unity API.
- Unity Editor / Play Mode здесь недоступен. Работу сборщика, компиляцию в целевой версии Unity, столкновения и устойчивость цепи требуется проверить в проекте. Пакет не заявляется как уже испытанная в Unity игровая механика.

Проверка в Play Mode: бросить без движения; бросить и отойти вбок; провести цепь возле столба; попасть в динамический куб; вызвать возврат; повторить с длинами 3/8/12 м. Обратить внимание на растяжение, дрожание и стоимость Physics в Profiler.

Документация API: https://docs.unity3d.com/ScriptReference/ConfigurableJoint.html и https://docs.unity3d.com/ScriptReference/Rigidbody.html .
